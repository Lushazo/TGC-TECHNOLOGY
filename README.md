# TGC Technology LTD — Website + No-Code Admin Portal

This is the GitHub-ready TGC Technology LTD website with a Decap CMS admin portal.

## Website

- One-page responsive website
- Mobile navigation
- White footer logo
- Facebook / Instagram / TikTok / LinkedIn footer icons
- News section with category filters and image slider
- User-provided background images retained
- Technology / Company / Jobs news cards

## No-code management

Open `/admin/` on the deployed site. The admin portal is configured to manage:

- Company details
- Social links
- Logos and favicon
- Website colors
- Homepage text
- Hero and section images
- Services and service images
- News posts, categories, dates, pictures, links and published status
- News section background and slider timing

## GitHub + Netlify

This package is configured for the recommended Decap CMS + Netlify Identity + Git Gateway setup. Git Gateway lets the CMS write changes into the GitHub repository without giving CMS editors direct repository write access.

See `CMS-SETUP.md` for the exact deployment steps.
